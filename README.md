# Creative-Coding-Project
This about Dear Data project
 My aim of this project to help me answer my question "Why am I using spending time on my phone for?". This is because it will help me understand more about my phone usage habits and discover the main reasons why I use my phone throughout the day. 
The data will be recorded by checking the amount of screentime I am using on my phone based on different categories I have divided into. 
These are Entertainment, Communication, Education, and Habits
The processing sketch will eventually display what categories I am using my phone for. This will be a visual representation of my collected data. My sketch will display various colours to show the reasons why I use my phone and how much time I spent on each activity.
